# Runtime legal material

The shared Jib configuration copies this directory into
`/licenses/knowledge-brain` in each application image.

`project-LICENSE.txt` and `project-NOTICE.txt` are byte-identical copies of the
repository's root LICENSE and NOTICE. Keep both copies synchronized whenever
the original project license or attribution changes.

Other files retain their component-specific licenses and notices. The project
Apache-2.0 selection does not replace them. Base-image legal material also remains
in its original image locations. This directory is retained legal material, not
a blanket clearance of every runtime dependency or external dataset.
