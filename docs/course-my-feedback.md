# Course own feedback overview

On /graph/groups, open Group -> Course -> 코스 내 피드백 열기. Fresh current registered OWNER/MEMBER/VIEWER sees only existing feedback on own submissions in Studies currently in canonical Course curriculum, independently of enrollment/private progress. OWNER also sees only own work. No-feedback submissions, peers, non-submitters and roster counts are absent. Empty curriculum produces an empty list. Removed links disappear on refresh; explicit source selection rechecks current Course binding then original Study/Assignment authority.

ALL is default. CURRENT means latest feedback targets current answer and its exact latest-version annotation is absent/restored. OUTDATED means an older answer, independently of withdrawal. RETRACTED filter includes explicit withdrawal on that latest feedback version for current or older answers, excluding unavailable metadata. Each row labels older-answer provenance and withdrawal separately. Unknown/missing marker state or a future source means UNAVAILABLE, never current. Historical annotations on older feedback versions cannot mark a newer comment. No unread/read tracking, approval, grade or completion meaning is added.

Fifteen fields extend the twelve-field Study own-feedback row with current Study ID/title and Course state. Current Study/Assignment labels preserve original submitted instruction and feedback-source answer versions and never rewrite Course selected Study snapshots/history. No comment, reason, answer, reviewer, score, rubric or file data is copied. The original source reads private text, original instructions, exact marker reason and immutable history; retracted original opinions retain existing authorized visibility. Independent refresh/filter preserve typed answer and Course edit drafts. Explicit selection opens fresh source, including same-Study different assignments.

GET /api/groups/{groupId}/courses/{courseId}/my-feedback accepts singleton filter/after/limit, canonical UUIDv7, no GET body, default20/max100, registered secure singleton session and no-store. Each request freshly authorizes participation through Space. Current VIEWER retains own reads; removed author loses access. One statement joins only local canonical Course/current curriculum/Study/Assignment/actor Submission/Feedback and exact latest feedback-version Retraction, with full tenancy/source/author tuples. Source/marker versions share one snapshot. Existing curriculum/catalog/Assignment-author/Feedback-submission/feedback-version marker keys support bounded reads. Filter precedes limit+1 and ascending Submission UUID keyset. Pages reflect current reads; refresh starts at the beginning. Archives retain reads without reopening writes.

Collapsed memory-only UI validates exact fields, enums, version/null/source/marker relationships, requested filter, common Course state and bounded ordered cursor. Failed/malformed/wrong-filter responses clear rows/cursor, show explicit retry and no false empty message. Hide/unmount aborts and clears; denial clears Group details. No polling or persistent browser storage. Stale curriculum blocks source navigation until refresh. No cross-owner SQL/FK, new ID/revision/Outbox, migration, published Proto, dependency/dataset, enrollment, notification or private progress/sharing mutation. Existing source writers, endpoints and overviews unchanged. Fixed submission.reads type=course-mine-feedback, pool/probes/traces apply without private content logging.
