# Study own-feedback overview

On /graph/groups, open Group -> Study -> 스터디 과제 -> 내 피드백 열기. Fresh current registered OWNER/MEMBER/VIEWER sees only existing feedback on own submitted work. OWNER also sees only own work here. The list excludes submissions without feedback, other authors and roster counts. Existing own submission/grade, own request and OWNER review/grading endpoints, response shapes and filter vocabularies remain unchanged.

ALL is default. CURRENT means latest feedback targets the current answer and its exact latest-version annotation is absent or RESTORED. OUTDATED means it targets an older answer, independently of withdrawal. RETRACTED filter includes explicit withdrawal on that latest feedback version for either current or old answer, excluding unavailable metadata. Each row separately labels old-answer provenance and withdrawal. UNAVAILABLE means unknown/missing marker state or future source; it is never treated as current feedback. Historical annotation on an older feedback version never marks a newer comment. No unread/read-tracking or approval/grade/completion meaning is added.

Twelve metadata fields contain submission/assignment IDs, current shared Assignment title/state, latest submitted version, original submitted instruction version/time, feedback status/version/source answer and exact marker state/version. No comment, reason, answer, reviewer, score, rubric or file contents are copied. Selecting a row explicitly opens the original freshly authorized Assignment/own submission; the existing component reads comment text, original instructions, marker reason and immutable history. Retracted original opinions remain visible there under existing policy.

GET /api/groups/{groupId}/studies/{studyId}/my-feedback accepts singleton filter/after/limit only, canonical UUIDv7, default20/max100, empty GET body, secure registered singleton cookie and no-store. Current Space participation precedes the owner database. Removed authors lose access; current VIEWER retains own work and current OWNER retains original review access through its existing endpoint. A single statement joins Collaboration-owned Assignment/Submission/Feedback and exact latest feedback-version Retraction metadata, with full source tuples and actor predicate. Filters precede limit+1 and ascending Submission UUID keyset. Existing catalog and Assignment/author, feedback/submission, marker/feedback-version unique keys support bounded reads. Pages are current reads; refresh starts from the beginning. No cross-owner SQL/FK, mutation, persistent ID/audit/Outbox, migration, published Proto, dependency/dataset, notification or private progress change. Fixed-label submission.reads type=study-mine-feedback, existing traces/pool/probes apply; private text is absent from metrics/logs.

Collapsed memory-only UI validates exact fields, numeric/null/marker/source relationships, requested filter, ordered cursor and page bounds. Failed/invalid reads clear rows/cursor and allow explicit retry without a false empty result. Filter/refresh preserve open answer drafts. Source selection opens fresh canonical data and never reuses overview metadata to write. Hide/unmount aborts/clears state; denied reads clear participant Group detail. Closed/archived sources retain reads without reopening writes. No polling or persistent browser storage.
