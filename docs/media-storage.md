# MinIO local storage dependency

Selected release: RELEASE.2025-10-15T17-29-55Z. The prescribed MinIO architecture remains unchanged. The community repository became archived/read-only on April 25, 2026 and releases are source-only. This is an explicit pinned local-development baseline, not a claim of ongoing upstream maintenance. Production release selection and support require review before public operation.

Primary sources: https://github.com/minio/minio and https://github.com/minio/minio/tree/RELEASE.2025-10-15T17-29-55Z . Original source archive: https://codeload.github.com/minio/minio/tar.gz/refs/tags/RELEASE.2025-10-15T17-29-55Z . SHA-256: be6d0bd3696c3a13a35f02d3a0280b64319c67918b4501c5c3d87f96d000085c.

The unmodified server is built with pinned golang:1.24.8-bookworm@sha256:4ed690d6649d63c312b99a6120025ec79ce3b542968a37da53d6236c7c61a848 using CGO_ENABLED=0 and release flags; a separate small administrative bootstrap executable sets private bucket versioning and scoped credentials. Scripts Build-LocalMinioImage.py, Prepare-MinioSource.py, Pack-MinioImage.py and MinioBootstrap.go document the reproducible process. The scratch OCI image includes the original source archive, AGPL license, bootstrap source and build-source manifest. It runs independently from application processes, nonroot, with read-only root filesystem and a writable mounted data PVC.

MinIO server: AGPL-3.0, permits commercial use under its license obligations. Redistribution requires preservation of notices and corresponding-source/build obligations; network-use obligations must be assessed for server modifications. Keep the included exact corresponding source and build instructions with distributed images; do not remove them. This records the chosen dependency and obligations, not a decision to publish a public service or proprietary combined product. Java SDK io.minio:minio:8.6.0 and explicit okhttp-jvm:5.1.0 are Apache-2.0, separately reviewed in media-dependency-review.txt.

Storage account brain-media-service can read bucket location/versioning and PutObject/GetObject/GetObjectVersion under uploads/* only. It cannot administer users/buckets, list the bucket, delete objects or access unrelated keys. Upload forms restrict uploads/staging/{space}/{media}; sealed uploads/sealed/{space}/{media} versions are generated internally and never issued as upload targets. Application secrets contain only this scoped account. Root credentials and TLS server private key remain in brain-data; Media trusts only the public CA and uses its own API leaf certificate in brain-apps.

Local public storage origin: https://localhost:9443, forwarded directly to TLS port 9000. Private internal origin: https://brain-minio.brain-data.svc:9000. The issuer signs the public host while using the fixed internal endpoint for byte verification. CORS is restricted to https://localhost:8443. The browser uploads bytes directly to MinIO; Gateway never proxies file bytes. API configuration and NetworkPolicies use the existing Helm/environment split.
