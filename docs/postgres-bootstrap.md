# PostgreSQL bootstrap

This configuration implements the permitted local co-location of independent databases. It does not merge service ownership or establish a production HA database topology.

PostgreSQL 17.11 is a supported current minor version verified against https://www.postgresql.org/support/versioning/ . PostgreSQL License permits commercial use and redistribution with required notices: https://www.postgresql.org/about/licence/ . The official image's OS and bundled components retain separate licenses; enumerate their notices and scan the image before distribution. Runtime image retrieval and execution remain unverified while Docker access is blocked.

Provision `brain-postgres-admin` and the 13 owner Secrets listed in values.yaml in namespace `brain-data`. Each Secret must contain a non-empty `password` key. Use distinct generated passwords through a secrets manager or a local Kubernetes Secret workflow; no plaintext password is embedded or generated by Helm. Applications must receive only their own credentials in `brain-apps`; never mount the admin or all-owner Secret bundle into a service.

The chart creates 12 service databases plus a separate Keycloak database. Gateway has no domain database. Brain Query and Activity databases are for owned read projections, not canonical facts. Each owner uses `brain_<owner>` as both role and database; each role lacks superuser, role creation, database creation, replication and RLS bypass privileges. PUBLIC access is revoked on every owner database. Logical WAL settings prepare for CDC; dedicated Debezium accounts, publications, replication slots and monitoring still require a separate setup.

```powershell
helm lint ./infra/charts/brain-postgres -f ./infra/environments/local/postgres-values.yaml
helm --kubeconfig ./.local/kubeconfig.yaml --kube-context k3d-knowledge-brain upgrade --install brain-postgres ./infra/charts/brain-postgres -n brain-data -f ./infra/environments/local/postgres-values.yaml --wait --timeout 5m
helm --kubeconfig ./.local/kubeconfig.yaml --kube-context k3d-knowledge-brain test brain-postgres -n brain-data
```

The Helm test checks all 13 owner logins and 156 rejected cross-database connections. These are executable integration checks, not yet executed or passed.

Initialization scripts run only on a new data volume. Changing a Secret or init script does not rotate an existing database password or migrate existing data. If initialization fails midway, inspect the volume and reconcile explicitly; never delete persistent data as an automatic retry. PVC size cannot generally be reduced in place. Backup/restore, production HA/TLS, network policy and credential rotation remain pending. The local single replica and resource values are initial budgets, not a measured capacity result.
